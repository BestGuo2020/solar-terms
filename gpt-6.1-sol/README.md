# 岁时 SUISHI · 二十四节气互动观测台

从空目录独立实现的 Three.js 双语科普网站。使用 Vite、TypeScript、Three.js 与 Astronomy Engine，不依赖后端。

## 运行

需要 Node.js 20.19+ 或 22.12+（本项目已用 Node.js 24 验证）。

```sh
npm install
npm run dev -- --port 5191 --strictPort
```

打开 http://localhost:5191/ 。如端口被占用，可改用其他端口。

```sh
npm test       # 天文、交节边界、跨年、坐标与内容完整性检查
npm run build # TypeScript 检查与生产构建，输出 dist/
npm run preview -- --port 5191 --strictPort
```

`dist/` 可部署到支持静态文件的站点。地球纹理已保存在项目中。Google Fonts 的 Noto Serif SC 为可选网络字体（SIL Open Font License），无法加载时自动使用系统宋体或衬线字体；主要功能无需外部服务。

## 功能与使用

- 默认读取设备真实时刻，所有时间固定显示为北京时间 `Asia/Shanghai`（UTC+8）。
- 当前已进入的节气区间、该区间的交节时刻、实时黄经与下一节气分别标识。
- 公转播放、暂停、0.25–30 天/秒调速、独立自转、日期时间选择、年份选择、年度拖动时间轴、回到今天。
- 支持 2000–2050 年；播放到上限后停止。内部计算前后年份事件，仅用于跨年区间衔接。
- 点击轨道、节气历、时间轴节气刻度或节气歌，都会暂停并跳到所选年份对应的交节事件。
- 鼠标拖动、滚轮、单指旋转和双指缩放；提供轨道总览、地球近景及默认视角按钮。聚焦 3D 画布后可用左右方向键旋转，`+` / `-` 缩放。
- 地轴、赤道、南北回归线与公转方向可以整体开关；近景显示辅助线图例。
- 中英文切换保留模拟日期，并记住语言偏好。小屏英文轨道用顺序编号和四个分至点全名，完整英文名称可通过标记的无障碍名称、详情和下方节气历读取。
- 24 条详情均含名称、顺序、黄经、交节时间、含义、季节、物候、农事和地方文化。详情内的三个标签可用左右方向键切换。
- 历史时间线、文化读本、四句节气歌、季节科普与参考来源完整提供双语版本。歌中重复字采用位置绑定，“暑”展开两个独立选择，“霜降”作为一个完整名称。

## 天文方法与精度

采用 Astronomy Engine **2.1.19** 的 `SunPosition` 与 `SearchSunLongitude`。两者使用一致的太阳地心视黄经（当日真黄道、真春分点）。按每个节气的目标黄经求根；月初或月中日期只提供搜索区间，不参与决定最终交节时刻。并非固定日期表或等时间插值。

交节时刻在内部保留毫秒，不对黄经直接 `floor` 来判断区间，避免根附近数值误差造成错位。交节时间与模拟时钟均显示至秒，以方便观察边界，不代表秒级天文精度；显示不向下一分钟取整，避免提前显示交节或跨入下一年。日期选择与浏览器所在时区无关。

算法的总体角位置精度目标约 **1 角分**，不等于秒级历书精度。太阳每天约移动 1°，1 角分对应的时间量级约 24 分钟；这是通用角位置目标的换算，不能作为具体年份的实测误差。

独立核对：使用[香港天文台 2026 年年表](https://www.hko.gov.hk/en/gts/astron2026/files/2026SolarTerms24.pdf)公布的 **12 个中气**作为测试基准，计算时刻距其印刷分钟值最大 **38.617 秒**。并未宣称独立核对了全部 51 年。未来 UTC 时刻还会受到地球自转预测与闰秒安排的影响。本站为教学演示，不是官方历书。

2000–2050 年的 **1,224** 个事件均检查了顺序、年份归属、目标黄经残差和交节前后 ±1 毫秒的区间归属。计算得到相邻事件间隔约 **14.7190–15.7329 天**。

## 坐标与模型简化

设太阳地心视黄经为 λ、示意轨道半径为 R，场景中的地球位置为：

```text
Earth(λ) = (−R cos λ, 0, R sin λ)
NorthAxis = (0, cos ε, −sin ε), ε = 23.44°
```

这是物理黄道坐标到 Three.js `y-up` 坐标的显式映射。地球位于地心所见太阳方向的反向；场景角度与太阳黄经不混用。λ=90° 时北极倾向太阳；λ=270° 时背向太阳；两个分点的太阳方向与地轴垂直。地轴倾斜组不会随公转转向太阳。

- 日地大小、距离和大气厚度均为示意比例，场景持续标注“不按实际比例”。
- 以圆轨道近似真实偏心率约 0.0167 的轨道；角速度由天文黄经连续驱动，仍保留不均匀的季节进程。
- 轴倾角固定，忽略一年内微小的岁差、章动变化与太阳黄纬；太阳置于原点，中心点光源驱动地球受光。
- 地球使用 NASA 2048 × 1024 Blue Marble 拼合影像，包含额外的原创程序云层与示意大气。它不对应实时天气。
- 自转为独立的 **24 秒/圈演示**，不代表所选时刻的真实经线朝向。暂停公转后仍可观察自转；关闭自转则固定表面朝向。
- 南北半球季节相反。传统节气季节不等于地方气象入季标准；地域差异在内容中分别说明。

## 性能、失败处理与验证

- 移动端降低球体分段与像素比，轨道刻线合并绘制；可手动切到低功耗或高画质。
- 页面隐藏时不渲染，观测台滚出屏幕后停止 GPU 绘制；时间交互只使用一个时钟。
- 页面退出时清理监听、控件、几何体、材质、纹理与 WebGL 上下文。
- 显示地球纹理加载状态；失败时使用蓝色球体并明确提示。WebGL 不可用时，节气内容和时间控件仍工作。
- 浏览器检查包含 24 个标记逐一跳转、四个分至点黄经、年初年末、闰日输入、公转播放暂停、语言切换、节气歌重复字与“暑”的双选。手机与平板使用浏览器响应式视口检查；未在实体触屏设备上执行测试。
