# 岁时 · 二十四节气天文馆

一个可独立运行的中英双语互动科普网站，以 Vue 3、Vite、Three.js 与 Astronomy Engine 实现。包含太阳和地球的三维场景、24 节气详情、独立公转/自转控制、北京时间时间轴、历史与文化、互动节气歌、科学说明和引用资料。

## 运行

需要 Node.js 20.19+（建议 Node.js 22 或 24）。在此目录执行：

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173/`。可使用 `npm run dev -- --port 5174` 指定其他端口。

```sh
npm run build
npm run preview
```

`dist/` 为可直接部署的静态网站。所有计算在浏览器本地完成，不需要后端、API Key 或实时历法接口。NASA 地球和云层纹理包含在项目中。完整 Noto Serif SC 字体也保存在本地，不请求 Google Fonts 或其他 CDN。`base: ./` 和相对素材路径支持复制到静态站点子目录；访问目录时使用结尾的 `/`。

## 长期保存与离线运行

网站没有预设的到期年份。日期输入与真实时钟不再受 2050 年限制；天文模型的计算窗口和网页能否使用分别处理。建议同时备份源码、`package-lock.json`、`public/` 和已经构建好的 `dist/`，不要只保存域名。

**已构建的离线版不需要 npm、API、账号或互联网。** 保留 `dist/` 与 `tools/serve.mjs` 的相对位置，安装 Node.js 后运行：

```sh
node tools/serve.mjs
```

打开 `http://127.0.0.1:5175/`。也可使用 `node tools/serve.mjs --port 8080`。浏览器一般不允许通过 `file://` 直接加载 ES 模块，因此请使用这个仅依赖 Node.js 标准库的本机服务器。不要把浏览器临时缓存当作备份。

`releases/solar-terms-portable.zip` 是交付时的快照，包含源码、锁文件、测试、素材、许可、文档、`dist/` 与离线服务器。没有发布凭证、Sites 项目标识、`node_modules`、个人浏览器资料或测试截图。解压后可以直接运行上述命令。

`dist/` 和本地 `releases/` 不纳入 Git 仓库。从 GitHub 克隆源码后，先执行 `npm ci`、`npm run build`，即可生成本机的离线运行文件。

从源码重新构建仍需按锁文件取得构建依赖；保存 `dist/` 能避免运行已有版本时依赖 npm 仓库持续可用。若需要在完全隔离的环境重新开发，请另存已安装的构建工具链或依赖镜像。网站可迁移、可备份，不代表浏览器、操作系统、域名和天文精度永远无需维护。

## 中英双语

页面右上角的 **EN / 中文** 按钮可以即时切换语言。首次访问按照浏览器支持的语言偏好选择中文或英文；之后优先使用本机保存的选择（`localStorage` 的 `suishi.locale`）。存储不可用时仍可切换，只是不跨刷新记忆。

- 界面、无障碍标签、24 节气详情、历史文化、科学说明、来源标题和远期示意提示都有英文版本；页面 `lang`、标题和描述同步更新。
- 切换语言保留模拟日期、已选节气、播放状态与相机模式，不重新创建 Three.js 渲染器。日期始终使用 UTC+8，英文显示日/月名/年份，公元前年份显示 BCE。
- 英文详情同时保留英文名称、拼音与中文原名。宽场景轨道用拼音，窄场景用编号；完整名称和对应编号位于下方列表，标记的无障碍名称和悬停提示始终完整。
- 节气歌保留中文原句，提供英文逐句解释和操作标签；重复字以及同时对应小暑、大暑的“暑”仍按稳定 ID 联动。
- 所有翻译均随源码与离线包保存，不调用在线翻译服务。资料链接指向原始出版物，其中部分为中文。

维护位置：`src/i18n/messages.js` 管理界面文本，`src/i18n/index.js` 管理语言状态，`src/data/terms.en.js` 管理英文内容。中文术语 ID、黄经和计算数据仍来自原始数据模块，语言切换只改变展示。

## 操作

- 首次进入使用系统真实时间，以北京时间 `Asia/Shanghai` / UTC+8 显示。现实时间与模拟时间有明确标签。
- 年份输入框支持直接输入，并提供上一年、下一年按钮；年份按需计算，不创建几千项下拉列表。
- 计算正常时，点击轨道标记、列表或歌诀会暂停播放，跳至该年的交节时刻。示意模式下，点击只切换节气示意，保留所选日期。
- 日期选择、年度时间轴、年份、播放速度及“回到今天”均修改同一模拟时钟。
- 天文模式播放速度为 1、3、10、30 天/秒；独立示意模式为 1、3、10、30 度/秒，日期不随示意播放改变。自转可独立关闭，速度为 20 秒/圈。
- 鼠标拖动旋转、滚轮缩放，触屏单指旋转、双指缩放。聚焦三维画布后，方向键旋转，加减键缩放；也可使用轨道总览、地球近景和恢复默认按钮。
- 场景右下角打开地轴、赤道、南北回归线、公转箭头和画质设置。
- 历史、文化、歌诀、科学问题与全部参考资料位于下方。歌诀“暑相连”展开为小暑、大暑两个按钮；重复字以所在位置绑定节气 ID。

## 数据、坐标与精度

`src/ephemeris.js` 是可替换的天文计算提供器，使用 Astronomy Engine **2.1.19** 的 `SunPosition().elon` 和 `SearchSunLongitude()`，包含视太阳位置所需的光行时、岁差和章动处理。它扫描所选年份真实的太阳黄经，用最长 8 天的区间寻找每个 15° 跨越，再求解交节时刻；不依赖固定的月初／月中日期窗口，也不均分一年。

- **没有业务截止年**：目前日期类型能表示的完整年份为 −271820 至 275759，来自 JavaScript `Date` 的固有限制，不能写成无限精度或真正无限的年份。只有到这个工程边界才安全停播；不会把系统真实时间夹到 2050 年。
- **计算窗口**：当前提供器对天文编号 **−1999 至 3000** 年启用求解，边缘额外计算一年来判断跨年区间。该窗口参考所用 [ΔT 多项式资料的覆盖时段](https://eclipse.gsfc.nasa.gov/SEhelp/deltatpoly2004.html)，是本站的保守应用策略，**不是 Astronomy Engine 的硬上限，也不是整个范围的准确度保证**。它可以随模型更换与验证工作调整，而不会改变日期或内容模块。
- **状态分级**：2025、2026 年显示“含已对照样本”；其他可计算年份显示“预测计算值”。超出窗口、出现非有限值、求根失败或结果不完整时显示“独立节气示意”。示意模式中交节时间为 `null`、年度交节刻度为空，隐藏“已进入的节气区间”和区间进度，保留真实的所选日期，绝不套用另一个参考年份。
- **示意播放**：黄经角度独立推进，按度/秒标注；日期选择和时间轴仍可使用，但不暗示该日期与当前演示的节气相对应。
- **历法规则**：使用前推公历与天文年编号；0 年为公元前 1 年，−1 年为公元前 2 年。UTC+8 是统一展示约定，不主张古代实际存在北京时间。修正了原生 `Date.UTC` 对 0—99 年的特殊解释。
- 程序时间统一保存为 UTC 毫秒，界面明确转换为 UTC+8；不依赖浏览器所在时区。
- “当前节气”按 `[本次交节, 下次交节)` 判断。1 月初正确延续上一公历年的冬至区间。
- 求根收敛容差为 **0.01 秒**，但这不是模型的实际准确度。界面显示秒，是为了准确定位本模型定义的边界，不能理解为秒级官方历书精度。
- 独立校验：香港天文台 2025、2026 年公布的 24 个中气分钟样本，最大绝对差异 **38.617 秒**。这是与已取整到分钟的表值比较的结果，不代表全部年份有同样误差保证。2000—2100 年及若干古代、远期样本已检查数值根、顺序与边界；未对整个计算窗口逐年作官方历书外部核验。
- Astronomy Engine 总体设计目标约为 1 角分的天体位置准确度；实际太阳计算在当前年份的误差通常远小于这个通用目标。正式历法请以权威历书为准。

场景使用 `+Y` 为黄道北极方向，太阳位于原点。令太阳地心视黄经为 λ：

```text
地球位置 = (-r cos λ, 0, +r sin λ)
地轴北向 = (0, cos ε, -sin ε)，ε = 23.44°
```

这里 λ 是太阳黄经，不能直接当成场景坐标系中的地球方位角。夏至 λ=90° 时地球位于 +Z，北轴朝 -Z 倾斜，因此北半球朝向太阳；冬至相反；两分时地轴与日地连线垂直。地轴倾斜组只平移、不随公转转向，自转发生在其子组中。

## 模型简化

1. 天体尺寸与日地距离不按真实比例，已在场景标注；地球半径相对轨道被放大以便看清。实际日地距离由 `HelioDistance` 计算，轨道引导线采用偏心率 0.0167 的近圆椭圆示意。
2. 地轴一年内保持同一方向，固定采用 23.44°，忽略其缓慢进动与细小变化。视黄经映射到平面场景，省略极小的黄纬变化。
3. 地球自转使用独立的教学速度，不表示真实格林尼治角或当地实时昼夜。太阳直射纬度由固定倾角模型近似计算。
4. NASA 地表及云层是历史卫星数据的静态合成图，并非所选日期的地表或实时天气。太阳表面、光晕、星空为代码生成的示意效果。
5. 春夏秋冬采用中国传统四时（立春、立夏、立秋、立冬起），并非各地气象入季。南北半球季节相反；中国各地区气候、农事和习俗差异均在正文说明。

## 性能与可访问性

天文年表只按需生成，最近使用缓存最多 32 个年份，失败记录同样受限并避免每帧重复求解。当前年与相邻年用于区间判断，不预计算整个窗口。

移动端降低球体分段、像素比和星点数量；提供节能画质，限制至约 30 fps。页面隐藏时暂停动画循环；场景离开视口时停止 GPU 绘制。卸载时断开观察器、事件与动画循环，释放几何体、材质、纹理、OrbitControls 与渲染上下文。太阳角度线复用缓冲区。纹理失败显示网格球体，缺少 WebGL 仍可使用完整历法、控制及文字内容。

主要操作使用原生按钮、输入控件与可见焦点。提供跳过导航、画布键盘操作、视角按钮、辅助线文字标签、错误提示及移动端独立详情/控制区域。
