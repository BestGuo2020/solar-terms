# 四时天文台 · 二十四节气观测台

一个以 Three.js 地日模型为核心的中英双语科普网站。打开页面即显示此刻的地球位置、太阳视黄经和已进入的节气。地球影像与四季插画均随项目提供，历算在浏览器内完成。

## 运行

建议使用 Node.js 22.12+ 或 24。在项目目录中执行：

```sh
npm ci
npm run dev
```

打开终端打印的本地地址。生产构建、预览与自动化测试分别使用：

```sh
npm run build
npm run preview
npm test
```

`dist/` 可以部署在静态站点的域名根目录。用手机测试时，可运行 `npm run dev -- --host 0.0.0.0`，在同一局域网内访问终端显示的 Network 地址。

## 如何观察

- **看节气变化**。点击任一轨道标签或图鉴条目，进入所选公历年该节气的交节瞬间。右侧卡片显示交节所在分钟，详解显示模型预报的秒数、名称含义、地域物候、农事与风俗。
- **调节时间**。播放以模拟天数推进，1× 代表每秒一天。可拖动年度时间轴，选择年份，或输入北京时间。天象状态会标记为“模拟时间”。“回到今天”恢复实时跟随。
- **观察地轴**。依次选择夏至和冬至，在“辅助标识”中打开地轴、赤道和回归线。北半球在夏至倾向太阳，在冬至背向太阳。地球自转有独立开关。
- **改变视角**。拖动旋转，滚轮或双指捏合缩放。星图获得键盘焦点后可用方向键旋转、加减键缩放，Home 恢复总览。时间轴的方向键移动一天，Page Up/Down 移动三十天。
- **读节气歌**。下方四时人文志收录历史、文化、节气歌与天文解读。“春”“夏”“雪”等按句中位置分别映射。第二句的“暑”合指小暑与大暑，点开即可二选一。

## 时间、坐标与精度

支持的公历年份为 **2000—2050 年**，统一使用北京时间（Asia/Shanghai，UTC+8）。年份起止均取北京当地午夜。元旦到小寒之前，当前区间仍始于上一年的冬至。

`src/astronomy.js` 使用 Astronomy Engine 2.1.19 的 `SunPosition` 计算太阳地心视黄经，以 `SearchSunLongitude` 求每个目标角度的交点，然后在交点附近细化毫秒边界。传统顺序从立春开始，立春为 315°，春分为 0°，每个节气前进 15°。区间采用左闭右开规则。年度交节结果会被缓存。[算法文档](https://github.com/cosinekitty/astronomy/tree/master/source/js)

`src/time.js` 维护一个模拟时间戳，负责实时跟随、播放、暂停和跳转。`src/main.js` 将同一次历算结果传给星图、轨道标记、年份、时间轴和卡片。界面省略秒数时显示该瞬间所在分钟，太阳黄经截取至 0.01°。

**独立历表核验**覆盖 2026 年全部 24 项。计算结果与香港天文台公布的 UTC+8 时刻逐项相差均不足一分钟。毫秒用于稳定判断交界，模型的实际天文精度取决于历算方法。其他年份的时刻未经逐年逐项外部历表比对。[香港天文台 2026 年交节数据](https://www.hko.gov.hk/en/gts/astronomy/data/files/24SolarTerms_2026.xml)

### 三维模型的简化

- 场景先将太阳地心视黄经加 180° 得到地球所在的相对方向，再施加固定的展示方位旋转。轨道近似为圆，角位置按实际计算的黄经非匀速推进。
- 太阳、地球的尺寸与日地距离均作了示意缩放。光源位于太阳中心，并保留少量环境光以帮助辨识地表。地轴相对轨道法线倾斜 23.44°，在场景空间中固定。地球自转用独立的演示速度呈现。
- 云层为历史卫星合成影像，星空与太阳表面由程序绘制。海陆和云层纹理加载失败时，保留示意球体及交互。WebGL 不可用时，Canvas 2D 使用同一轨道、相机、地轴与太阳方向进行投影。
- 移动设备限制像素比与渲染帧率，页面隐藏时停止动画循环。页面退出时释放纹理、几何体、材质、控制器和渲染器。

## 内容与资源

`src/content.js` 收录全部双语节气条目、历史时间线、文化实例、四句歌诀、三项科学解说及参考资料。`src/reading.js` 组织阅读内容，`src/scene.js` 与 `src/sky.js` 负责三维场景和程序纹理。

历史与文化说明参考香港天文台、中国非物质文化遗产网及 UNESCO。气候和农事举例注明适用地区，诗词随文标出作者与篇名。完整资料入口在页面右上角及文末。[UNESCO 非遗名录](https://ich.unesco.org/en/RL/the-twenty-four-solar-terms-knowledge-of-time-and-practices-developed-in-china-through-observation-of-the-suns-annual-motion-00647) · [香港天文台的节气与黄经说明](https://www.hko.gov.hk/en/gts/time/24solarterms.htm)

地表和云层取自 NASA Goddard Space Flight Center 的 Blue Marble（2002），署名 Reto Stöckli、Robert Simmon，依 NASA 媒体使用准则用于教育展示。24 幅节气插画由本项目使用 ImageGen 生成，按所选节气载入。[插画文件与绘制提示](docs/illustrations.md) · [NASA 影像来源](https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/) · [NASA 媒体使用准则](https://www.nasa.gov/nasa-brand-center/images-and-media/)

## 验收范围

`npm test` 检查 51 个年份的 1,224 次交节，覆盖顺序、黄经、交节当刻及前一毫秒、跨年和闰年。另有 2026 年独立历表比对、四个分至点受光关系、双语字段完整性与四句歌诀映射测试。

浏览器验收覆盖 320、390、768、1024、1440 像素宽度，以及节气跳转、播放与暂停、日期输入、年度时间轴、视角切换、中英文阅读、触屏操作和资源降级。
